The game is paused while this panel is open. Press ` (backquote), F10 or Esc to close.

Controls

Esc opens the menu and Enter selects; these can't be rebound. Some browsers keep Ctrl+W, Ctrl+number and (on macOS) Ctrl+arrow for themselves, so Z / X are bound for jump / pogo as well.
